# DSLEsolang

Pour ce devoir, j'ai choisi le langage ArnoldC (https://esolangs.org/wiki/ArnoldC) et j'utilise l'interpréteur en ligne suivant : https://tio.run/#arnoldc. Pour lancer p, il suffit d'appuyer sur le bouton play en haut à gauche après avoir choisi le nombre à tester ligne 2 (DO IT NOW palindrome nombre_à_tester). Cependant le langage ne supporte que les entiers signés sur 16 bits et le programme ne fonctionne que pour les nombres positifs, l'entier à tester doit donc être compris entre 0 et +32 767.

Le langage ne supporte pas les commentaires, j'ai donc déposé une version fonctionnelle sans commentaires (p.arnoldc), et une version non fonctionnelle avec des commentaires signalés par le caractère # (p_comments.arnoldc).
